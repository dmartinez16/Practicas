# 📘 Practicas – Desarrollo de página web informativa

Este repositorio contiene ejercicios y prácticas enfocados en el desarrollo de una **página web informativa** usando tecnologías web como **HTML, CSS y JavaScript**, organizados en la rama principal del proyecto (*Rama-Main*).

---

## 🧩 Descripción

El objetivo de este repositorio es servir como un conjunto de prácticas/webs que permiten aplicar conceptos básicos de desarrollo frontend, tales como:

- Estructura de páginas web con HTML.
- Estilos y diseño visual con CSS.
- Interactividad y manipulación del DOM con JavaScript.

Este proyecto puede incluir ejemplos de funcionalidades típicas de páginas informativas (menús, secciones, efectos visuales, etc.).

---

## 🚀 Tecnologías utilizadas

El proyecto está desarrollado con:

- **HTML** — Estructura del contenido web. 
- **CSS** — Estilos visuales y diseño.
- **JavaScript** — Interactividad y comportamientos dinámicos.
